# ieee-robot

**Ruleset**: https://docs.google.com/document/d/1g6Eb3Ngv5g4ZNUFfK-9r6EEk7T_82anK/edit

### Available components:

Power source:
-  AA NiMH batteries
- Buck converter (LM2596)

Sensors:
- Ultrasonics (RCWL-1601)
- IR sensors (TCRT5000)

Motors:
- DC gearmotors (N20, 100:1, 100rpm)
- Motor driver TB6612FNG

Brains:
- ESP32 (ESP-WROOM-32)
